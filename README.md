Interactive wedding invitation website with object-based navigation. Built with Next.js

**IN PROGRESS**

## Features
- Interactive navigation
- Real-time RSVP and guest messages (Via Supabase)
- Countdown timer to event date
- Photo gallery sections
- Mobile-first 9:16 aspect ratio design
- Background music player
- Copy-to-clipboard for bank account details
- Smooth animations with Framer Motion

## Tech Stack
 
- **Framework**: Next.js 14
- **Database**: Supabase
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Britney, Quicksand, Chillax (via Fontshare)
